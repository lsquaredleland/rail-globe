# Rail Globe spec: Overview

As of 2026-10-20 · Leland

Rail Globe is a static web map of passenger rail built from OpenStreetMap. Its purpose is comparison: put city or region A next to city or region B, at the same real scale, and see the difference in magnitude.

## Goal and direction

- **Primary content:** passenger rail infrastructure (track, stations, platforms, station grounds, yards) and the services that run on it (lines from OSM route relations).
- **Core use:** compare two regions side by side, e.g. the SF Bay Area vs Paris, with totals for each.
- **Magnitude, not just lines:** station and yard outlines are drawn so the physical footprint of the railway is visible. Yards are cheap in file size, so they are shown.
- **Readable by default:** a minimal basemap, standard rail types, and a choice between type colours and operator colours.

## Scope

| In v1 | Parked (not in v1) |
| --- | --- |
| Passenger track, stations, platforms, station grounds, yards | GTFS of any kind: frequencies, timetables, Portolan, train animation |
| Lines from OSM route relations; China services from a 12306 snapshot | Live train positions |
| Two colour modes: by rail type, by operator colour | History timeline (`start_date` is kept in the data for later) |
| Standard rail types (high-speed to tram) | Comparing custom drawn areas |
| Compare view for preset regions | Routing |
| Local name on the map; local + English in tooltips | Accounts, saved views |
| Freight and construction track, each with a visibility toggle | Abandoned and disused track (dropped); proposed track (kept for Hong Kong only, a test, off by default) |
| Pilot: three regions, then one country, then the world (the world is built and deployed, 2026-10-16) | Signalling and owner themes |

**Scope and delivery**
- Static only: no server, no GTFS, no live data. [2026-10-04-static-delivery](#2026-10-04-static-delivery), [2026-10-11-no-gtfs](#2026-10-11-no-gtfs)

- Abandoned and disused track is dropped; proposed is kept for Hong Kong only (a test, off by default). [2026-10-11-abandoned-dropped](#2026-10-11-abandoned-dropped), [2026-10-12-proposed-hong-kong-only](#2026-10-12-proposed-hong-kong-only)

**Stations**
- Rank and zoom come from physical size only, never from line counts. [2026-10-10-station-rank-physical-size](#2026-10-10-station-rank-physical-size), [2026-10-11-station-size-weights](#2026-10-11-station-size-weights)

- Stations under construction show only while Construction is on. [2026-10-11-stations-under-construction](#2026-10-11-stations-under-construction)
- Airports: outline and terminals are infrastructure; plane icon at commercial airports. [2026-10-11-airports](#2026-10-11-airports)

**Rail types and freight**
- Commuter is merged into Regional; monorail and funicular are own types; light rail and tram are one type. [2026-10-12-commuter-merged](#2026-10-12-commuter-merged), [2026-10-12-monorail-funicular-types](#2026-10-12-monorail-funicular-types), [2026-10-11-light-rail-tram-one-type](#2026-10-11-light-rail-tram-one-type)
- High-speed is a property of the track, not of its services; China uses 250 km/h, elsewhere 200. [2026-10-16-high-speed-track-property](#2026-10-16-high-speed-track-property), [2026-10-11-china-high-speed-rule](#2026-10-11-china-high-speed-rule), [2026-10-11-china-high-speed-overrides](#2026-10-11-china-high-speed-overrides)
- Short track pieces take the type of the track they join. [2026-10-16-short-piece-smoothing](#2026-10-16-short-piece-smoothing)
- Track with no name takes its railway relation's name. [2026-10-16-track-named-after-railway](#2026-10-16-track-named-after-railway)
- Freight and passenger: freight is never guessed from "untagged"; passenger needs evidence in North America, Argentina and Africa. [2026-10-14-freight-evidence-based](#2026-10-14-freight-evidence-based), [2026-10-14-freight-evidence-stray-pieces](#2026-10-14-freight-evidence-stray-pieces), [2026-10-16-freight-north-america](#2026-10-16-freight-north-america), [2026-10-16-freight-argentina-africa](#2026-10-16-freight-argentina-africa)
- Freight track is drawn muted grey with its own toggle. [2026-10-11-freight-muted-grey](#2026-10-11-freight-muted-grey)
- A hybrid system's type comes from the route `service` tag, else a per-region override. [2026-10-11-hybrid-systems](#2026-10-11-hybrid-systems)

**Pipeline**
- Extraction, classification, station model and tiles are all Rust (`pipeline/rail-extract`); no Python, tippecanoe or osmium in the build. - Tiles are MLT, written by the Rust writer. [2026-10-14-mlt-only](#2026-10-14-mlt-only)
