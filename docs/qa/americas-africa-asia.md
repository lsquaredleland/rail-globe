# Map QA: North America, Latin America, Africa, Middle East, South Asia (2026-10-17)

Scope: US, Canada, Mexico, Brazil, Argentina, Chile, Colombia (and Peru, Bolivia, Uruguay, Venezuela, Dominican Republic as a side look), Egypt, Morocco, South Africa, Nigeria, Kenya, Ethiopia, Israel, Saudi Arabia, UAE, Iran, India, Pakistan, Bangladesh, Sri Lanka.

Method. Dev server on port 5195 reading the local world build (`app/public/data/world`), driven by headless Chrome (puppeteer-core, not the shared browser). 21 country views (z2.6 to z6.5) and 33 city or hub views (z9.6 to z13; colour mode Rail type, labels English and local), each opened and looked at. Data side: `data/world/<cc>/{features.typed.geojsonl,lines.json,complexes.geojsonl,stations.geojsonl,classify_report.json}` and `app/public/data/world/<cc>/stats.json`. Tests ran in an isolated copy of the pipeline (own binary, own config folder, own output folder), not in `data/world`. Nothing was committed; no world build was run.

Reference sources: Wikipedia (Amtrak, VIA, Gautrain, Madaraka Express, Tren Maya, Transportation Technology Center, Addis-Djibouti), BTS NARN as used in `docs/13`, docs/07 and docs/15. Where a claim is from memory and not looked up it says "not verified".

Uruguay. The requirement was to keep the Montevideo suburban service. No such service exists to keep: the minister said in April 2026 that Montevideo-Progreso passenger trains will be reactivated "in the coming years", and El Observador reports the Ferrocarril Central "currently carries only freight" (https://www.elobservador.com.uy/nacional/etcheverry-tiene-firme-expectativa-que-bastante-antes-2029-se-reactive-tren-pasajeros-montevideo-y-progreso-n6040870); the 2018 Montevideo-Empalme Olmos line is not mentioned as running. Nothing in `data/world/uy` carries a passenger route there (the only route relation is AFE Tacuarembo-Rivera, 118 km, which stays), and no 25 de Agosto service was found. An exemption keeping Montevideo-Progreso would draw a service that does not run, so none was added. If AFE restarts a service, add an exemption on the AFE ways (unnamed, `operator=AFE`, 48 km) with that source. Needs the user's confirmation if they know of a running service.

Peru, Bolivia, Cuba (numbers only, not applied).
